## Statut d’intégration

Les descriptions courtes actuellement utilisées pendant le jeu restent
inchangées.

Les biographies approfondies ne sont pas encore affichées dans
l’application.

Le volet réservé au formateur reste un contenu documentaire. Il ne doit pas
être intégré aux données chargées par le navigateur sans décision
éditoriale et technique spécifique.

Les informations dites confidentielles sont confidentielles dans l’univers
narratif des personnages. Elles ne constituent pas des données réelles sur
des personnes existantes.
