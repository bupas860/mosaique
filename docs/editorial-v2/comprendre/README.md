# Espace « Comprendre » — corpus canonique

Ce dossier réunit les sources validées du futur espace public « Comprendre ».

## Sources publiques

- `modules/` contient les douze modules canoniques M01 à M12. M01, M02 et M08 utilisent exclusivement leur version V3 ; les neuf autres modules utilisent exclusivement leur version V2.
- `transversal/080_Espace_Comprendre_Sommaire_et_parcours_de_lecture_V2.md` fournit le sommaire et les quatre parcours.
- `transversal/081_Espace_Comprendre_Glossaire_transversal_V2.md` fournit le glossaire canonique.
- `transversal/082_Espace_Comprendre_Matrice_des_renvois_V3.md` fournit uniquement les renvois approuvés.
- `transversal/083_Espace_Comprendre_Bibliographie_generale_et_index_des_sources_V3.md` fournit uniquement les références publiques S001 à S164.

## Sources internes de contrôle

Le dossier `internal/` contient l’audit d’harmonisation 079 V2 et la spécification d’intégration 084 V3. Son contenu ne doit jamais être exposé dans les données chargées par le navigateur.

Les dossiers de recherche, versions historiques, brouillons et copies suffixées ne font pas partie du corpus. La génération publique est pilotée par une liste d’autorisation explicite et ne parcourt jamais automatiquement ce dossier.
