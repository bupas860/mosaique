## 1. Règles de résolution des liens

Un lien vers une situation utilise toujours son code et son titre canoniques. Aucun lien vers un personnage n’est approuvé en l’absence d’un identifiant P ou XP explicitement présent dans la source : un prénom partagé ou une situation commune ne suffit pas. Aucun lien vers un mécanisme n’est approuvé en l’absence d’un identifiant canonique validé dans la banque gelée.

Les dépendances pédagogiques signalent un appui utile. Elles ne bloquent pas l’ouverture d’un module. Les liens vers « Jouer » et « Explorer » sont des cibles fonctionnelles proposées ; ils ne rendent pas publics les dossiers de recherche, les audits ou les données internes.

## 6. Renvois au mode Découverte

Le mode Découverte peut être proposé depuis M01 et M12, et comme entrée transversale depuis le sommaire. Ses règles restent gelées : galerie P01 à P09 ; dix situations ; trois V, trois N, quatre I ; aucune X ; exactement deux protections issues de deux modes différents ; huit situations non protectrices ; famille analytique cachée avant la décision puis révélée dans le feedback ; bilan sans note morale.

Il ne doit pas être indexé comme un cinquième niveau de gravité, ni renommé « Découverte intersectionnelle ».

# Statut fonctionnel des renvois

## Renvois approuvés

Sont approuvés :

- les liens vers les modules M01 à M12 ;
- les liens vers les notions du glossaire énumérées dans la présente matrice ;
- les liens vers les vingt-quatre situations du registre canonique ;
- les liens vers un mode ou vers « Jouer », si la route correspondante existe ;
- les liens vers « Explorer — situations », si la route correspondante existe.

## Renvois approuvés sous condition de résolution de route

Un renvoi approuvé n’est activé que si sa route existe. Si la route n’existe pas, le code ou le titre informatif est conservé sans lien cassé ; la cible est signalée comme indisponible sans masquer le contenu du module. Cette condition n’autorise ni la création d’une page nouvelle ni la modification d’une route pour forcer l’activation du renvoi.

## Renvois non approuvés

Ne sont pas approuvés :

- les liens vers les personnages, aucun identifiant P ou XP n’étant explicitement validé dans les modules publics ;
- les liens vers les mécanismes, aucun identifiant canonique n’étant validé pour ces renvois ;
- les liens inférés à partir d’un prénom, d’un titre libre, d’une identité supposée ou d’une proximité thématique ;
- tout lien absent de la présente matrice.

Les homonymes documentaires entre les galeries P et XP restent distincts. Une ressemblance de prénom ou de contexte ne permet jamais de relier ni de fusionner deux personnages.
