# Matrice de jeu

## Rôle du document

Cette matrice définit le résultat associé à chaque combinaison entre une situation et un personnage.

- `+1` : le personnage avance d'une case ; la situation ne constitue pas un obstacle déterminant pour lui.
- `0` : le personnage reste sur place ; la situation constitue un obstacle pour lui.

Les explications pédagogiques ne figurent pas dans ce document. Elles sont regroupées dans un document distinct consacré aux débriefs.
