## 1. Note méthodologique

### 1.1. Fonction du texte alternatif

Le texte alternatif restitue les éléments visuels nécessaires pour comprendre et distinguer un portrait lorsque l’image n’est pas perçue. Il privilégie l’âge apparent, la posture, l’expression, la coiffure, les vêtements, les accessoires, les aides techniques visibles et, lorsque cela est utile, le décor.

Les dix-sept portraits relèvent d’un même style illustré semi-réaliste, lumineux et situé dans l’environnement du lycée. Cette caractéristique commune n’est pas répétée dans chaque texte alternatif afin de réserver la description aux différences significatives entre les personnages.

### 1.2. Différence entre texte alternatif, biographie et légende

Le texte alternatif n’est ni une biographie abrégée ni une légende éditoriale. Il ne raconte pas le parcours du personnage, ne résume pas ses caractéristiques opératoires et ne révèle pas une information simplement parce qu’elle figure dans les documents biographiques. Il décrit le portrait effectivement associé à l’identifiant.

Le prénom, l’âge, la classe, la galerie et l’identifiant sont affichés séparément dans l’interface prévue. Le texte alternatif peut donc se concentrer sur l’apparence du portrait sans répéter systématiquement le prénom.

### 1.3. Informations invisibles exclues

Aucune orientation sexuelle ou romantique, transidentité, non-binarité, intersexuation, pratique religieuse, neurodivergence, donnée médicale, relation, configuration familiale, origine nationale ou culturelle, situation économique, information administrative ou confidentialité narrative n’est déduite de l’apparence. Les formulations restent descriptives, même lorsque les documents éditoriaux confirment par ailleurs ces informations.

Lorsqu’un fauteuil roulant manuel est visible, il est mentionné comme un élément du portrait. Aucune cause du handicap, dépendance, souffrance ou nécessité d’assistance n’est ajoutée.

### 1.4. Identifiants stables et homonymes

L’identifiant stable `Pxx` ou `XPxx` constitue la clé de correspondance entre le portrait, le prénom et le texte alternatif. Il évite qu’un prénom seul serve à choisir une description.

Les quatre couples d’homonymes sont contrôlés à partir de leurs portraits réels : P01 Noé / XP08 Noé, P02 Jade / XP05 Jade, P05 Sofia / XP06 Sofia et P08 Lou / XP07 Lou. Chaque membre du couple possède un texte propre fondé sur sa coiffure, sa silhouette, ses vêtements, ses accessoires et sa posture.

### 1.5. Sources de contrôle

Les textes ont été établis conjointement à partir :

1. des dix-sept fichiers WebP effectivement utilisés par l’application ;
2. de `020_Casting_visuel_17_personnages_V1.md` ;
3. de `046_Biographies_approfondies_17_personnages_V1.md` ;
4. de `048_Matrice_affichage_17_biographies_V2.md`.

Le portrait reste la source principale. Les documents éditoriaux servent uniquement à sécuriser l’identifiant, le prénom, la correspondance du fichier et les éléments visuels déjà validés. Dans le tableau ci-dessous, l’intitulé « Texte alternatif approuvé » désigne la formulation proposée comme texte canonique ; l’ensemble du cahier demeure soumis à validation humaine.
